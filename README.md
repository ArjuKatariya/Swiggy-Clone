# Swiggy-Clone

A responsive **Swiggy Clone** web application built using **HTML, Tailwind CSS.**This project recreates the modern user interface of the Swiggy food delivery platform with a focus on clean design, responsiveness, and an enhanced user experience.

## Features

* Responsive design for mobile, tablet, and desktop
* Modern and attractive UI inspired by Swiggy
* Optimized using Tailwind CSS
* Clean and maintainable code structure

## Technologies Used

* HTML5
* Tailwind CSS

## Purpose

This project was developed to improve frontend development skills by practicing responsive web design, Tailwind CSS, and modern UI implementation while recreating a real-world food delivery website.
